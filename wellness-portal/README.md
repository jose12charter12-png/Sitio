# Wellness & Active Living — editorial website
A lightweight, bilingual (Spanish/English), static editorial site prepared for GitHub + Netlify Free deployment.

## Project structure
- `es/` Spanish experience
- `en/` English experience
- `assets/` shared CSS and JavaScript
- `robots.txt`, `sitemap.xml`, `ads.txt`: search and monetization readiness

## Deploy on Netlify
1. Import this GitHub repository.
2. Set **Base directory** to `wellness-portal`.
3. Set **Publish directory** to `.` (relative to the base directory).
4. No build command is required.
5. Assign a temporary `*.netlify.app` subdomain.

## Before launch / AdSense application
- Replace the example contact email with a monitored address.
- Publish a real privacy/cookie policy matching actual analytics, ad and affiliate tools.
- Add consent management appropriate to visitor regions before non-essential cookies or ad personalization.
- Add the approved AdSense publisher ID to `ads.txt` after Google issues it.
- Add GA4, Search Console, advertising pixels and affiliate IDs only after account ownership and consent setup.
- Publish a substantial body of original, reviewed articles and ensure navigation works.
- AdSense approval, search rankings, traffic and revenue cannot be guaranteed by any developer.

## Editorial and health standards
Content is educational, not personal medical advice. Avoid diagnosis, treatment promises, fabricated credentials, fake testimonials, fabricated product reviews and unsupported health claims. Cite reliable primary or institutional sources in full article pages.
